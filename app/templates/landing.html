Disk pipeline

  • Walks the filesystem with pytsk3, raw or E01
  • Finds executables by content, never by extension
  • 2,381 EMBER features reduced to 150
  • One verdict per file, with path, SHA-256 and MACB times

Memory pipeline

  • Nine Volatility 3 plugins, 55 features
  • Injected regions, hidden modules, rootkit artifacts
  • Evidence-led: observations first, model score second
  • Every capture carries an out-of-distribution check

Reporting

  • Indicator tags mapped to MITRE ATT&CK
  • Deterministic, visible severity scoring
  • PDF report plus CSV and JSON export
  • A limitations section that is never optional
This is a triage tool. It narrows an investigation to the artifacts worth a human's attention; it does not produce conclusive findings. Flagged items warrant manual verification, and MITRE mappings are investigative leads inferred from statistical indicators rather than observed runtime behaviour.
